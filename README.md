### About
- Vulo is a self-hosted PaaS (Platform as a Service) — a platform that abstracts the infrastructure so you only need to focus on your application.

- Instead of dealing with containers, ports, and resources manually, Vulo handles everything under the hood through a simple REST API or Web Interface, giving you a clean and straightforward deployment experience on your own hardware.
